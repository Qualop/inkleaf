# 글쓰기와 Markdown

## 하나의 문서를 세 가지 보기로

| 보기 | 쓰는 상황 |
| --- | --- |
| **작성** | 제목·목록·표 등의 서식을 보면서 편집합니다. 편집 중인 부분에는 Markdown 기호가 나타납니다. |
| **Markdown 원문** | 문서의 모든 Markdown 기호를 직접 확인하고 고칩니다. |
| **미리보기** | 편집하지 않고 완성된 문서 형태로 읽습니다. |

**보기** 메뉴에서 선택합니다. 왼쪽 아래의 원문 버튼으로도 원문 보기를 전환할 수 있습니다. 보기를 바꿔도 같은 문서와 편집 기록을 사용합니다.

![실제 Mac 앱의 Markdown 원문 화면](../../screenshots/source.png)

## 자주 쓰는 문법

````markdown
# 문서 제목
## 소제목

**굵게**, *기울임*, [링크](https://example.com)를 넣은 문단입니다.

> 인용문이나 기억할 내용을 씁니다.

- 목록의 첫 항목
- 목록의 다음 항목

- [ ] 할 일
- [x] 끝낸 일

```python
print("나의 메모")
```
````

**문단** 메뉴에서 제목, 목록, 인용문, 할 일 목록을 넣을 수 있습니다. **서식** 메뉴에는 강조와 링크 같은 명령이 있습니다. 기존 문구에 서식을 넣으려면 먼저 그 부분을 선택하세요.

## 표 편집하기

**문단 → 표 삽입 / 편집…**을 엽니다. 내용을 입력하고 행과 열을 추가·삭제하거나 정렬을 바꾼 뒤 적용합니다. 기존 표를 고칠 때는 표 안에 커서를 둔 상태로 같은 명령을 엽니다. 실행 취소하면 이전 Markdown으로 돌아갑니다.

```markdown
| 항목 | 상태 |
| --- | --- |
| 개요 | 완료 |
| 첫 원고 | 다음 할 일 |
```

## 각주와 참고 자료

**서식 → 각주**, **참조 링크…**를 쓰거나 문법을 직접 입력합니다.

```markdown
본문에 덧붙일 내용이 있습니다.[^note]

[^note]: 출처나 조금 더 긴 설명을 여기에 적습니다.
```

## 긴 글에 집중하기

**보기 → 포커스 모드**는 다른 문단을 흐리게 표시합니다. **타자기 모드**는 입력 중인 줄이 창 가운데 부근에 머물도록 스크롤합니다. 글꼴, 본문 너비, 줄 간격은 [화면과 설정](appearance-and-settings.md)에서 조절합니다.
