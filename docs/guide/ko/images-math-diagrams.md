# 이미지·수식·다이어그램

## 로컬 이미지 넣기

1. 이미지를 넣을 위치에 커서를 둡니다.
2. **서식 → 이미지 → 로컬 이미지 삽입…**에서 파일을 선택합니다.
3. 문서를 저장합니다. 아직 위치가 없는 임시 문서는 처음 저장할 때 참조한 이미지를 문서와 함께 저장합니다.

클립보드의 이미지를 붙여 넣거나 문서로 드래그할 수도 있습니다. 이미지 참조에 커서를 두고 **서식 → 이미지**에서 속성, 미리보기, 파일 관리 명령을 사용합니다.

```markdown
![이미지를 설명하는 짧은 문장](assets/photo.png)
```

상대 경로를 썼다면 문서와 이미지 파일을 함께 옮겨야 합니다. 다른 폴더에 문서를 저장할 때는 다른 이름으로 저장을 사용하고, Markdown을 공유할 때는 함께 생성된 `assets` 폴더도 전달하세요.

외부 이미지 주소는 해당 서버에 접속합니다. 외부 업로더는 **설정 → 이미지**에서 선택적으로 구성합니다. 로컬 이미지를 넣는 데는 업로더가 필요하지 않습니다.

## 수식 쓰기

본문 안의 수식은 `$…$`, 별도의 수식 블록은 `$$…$$`로 씁니다.

```markdown
본문 수식: $E = mc^2$

$$
a^2 + b^2 = c^2
$$
```

**설정 → 수식**에서 번호 매기기와 physics 지원을 선택합니다. 수식은 앱 안에서 렌더링합니다. **서식 → 수식**에는 선택한 수식을 복사하거나 지원하는 형식으로 저장하는 명령도 있습니다.

## 글자로 다이어그램 만들기

`mermaid` 코드 블록을 입력합니다.

````markdown
```mermaid
flowchart LR
    Notes --> Draft
    Draft --> Review
    Review --> Share
```
````

작성과 미리보기에서 다이어그램으로 표시됩니다. 모양을 바꾸려면 원문을 수정합니다. **서식 → 다이어그램**에서 선택한 다이어그램을 SVG로 복사하거나 저장할 수 있습니다.

![실제 문서에 표시된 수식과 흐름도, 코드](../../screenshots/technical.png)

[기술 문서 예제](../../examples/Technical%20Notes.md)를 열어 직접 바꿔 보세요. 오류가 표시되면 먼저 수식의 구분 기호나 다이어그램 문법을 확인합니다.
