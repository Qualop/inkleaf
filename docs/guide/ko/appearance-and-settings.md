# 화면과 설정

**Inkleaf → 설정…** 또는 **⌘,**로 엽니다. 관련 기능을 일곱 범주로 나누었습니다.

| 범주 | 설정할 수 있는 내용 |
| --- | --- |
| 일반 | 화면 언어, 이전 문서 열기, 임시 문서, 자동 저장, 외부 파일 변경 |
| 모양과 테마 | 테마, 글꼴, 너비, 줄 간격, 집중·타자기 모드, CSS, 앱 아이콘 |
| 편집 | 작성 모드, 줄 감싸기, 줄 번호, 들여쓰기, 기호 쌍, Markdown 문법 선호 |
| 맞춤법과 사전 | 맞춤법·문법 검사, 검사 언어, 개인 사전 |
| 이미지 | 선택적으로 사용할 외부 업로더 |
| 수식 | 수식 번호 매기기, physics 지원 |
| 내보내기 | 사용자 Pandoc 실행 파일 |

![Inkleaf의 모양과 테마 설정](../../screenshots/settings.png)

## 문서 테마 고르기

**테마** 메뉴에서 Default, GitHub, Newsprint, Night, Pixyll, Whitey를 선택합니다. 테마 관리에서 CSS를 가져오거나 사용자 테마를 편집·삭제할 수 있습니다. 글꼴, 글자 크기, 본문 너비, 줄 간격은 모양과 테마에서 조절합니다.

## 한 문서만 다르게 설정하기

설정의 **이 문서에만 설정 적용**을 켠 뒤 모양, 편집, 교정 옵션을 바꿉니다. 해당 문서를 공통 설정으로 되돌리려면 **문서 설정 초기화**를 누릅니다.

앱 아이콘, 화면 언어, 시작 동작은 앱 전체에 적용됩니다. 설정 화면에 표시되는 적용 범위 설명도 참고하세요.

## 앱 아이콘 고르기

**모양과 테마 → 앱 아이콘**에서 기본 **검은 잉크** 또는 **초록 잎**을 선택합니다. Dock과 앱 전환기에 표시되는 아이콘이 바뀝니다. Finder와 설치 파일에는 기본 아이콘을 사용합니다.

## 맞춤법과 개인 사전

**맞춤법과 사전**에서 자동, 한국어, 영어 중 검사 언어를 선택합니다. 빨간 밑줄은 맞춤법 오류 후보이며 문법 제안은 별도로 표시합니다. 밑줄을 누르거나 **⌥Return**으로 제안을 열 수 있습니다. 직접 선택하기 전에는 제안으로 문장이 바뀌지 않습니다.

개인 사전은 한 줄에 한 단어씩 입력합니다. 사전과 문법 결과는 macOS의 언어 지원에 따라 달라집니다. 표시된 제안이 문장의 옳고 그름을 확정하는 것은 아닙니다.

업데이트 설정은 **Inkleaf** 메뉴의 **업데이트 확인…**, **자동으로 업데이트 확인**에 있습니다.
