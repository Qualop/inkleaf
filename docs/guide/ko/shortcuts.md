# 키보드 단축키

Mac 앱 기준입니다. ⌘는 Command, ⌥는 Option, ⇧는 Shift입니다.

| 작업 | 단축키 |
| --- | --- |
| 새 문서 | ⌘N |
| 새 창 | ⇧⌘N |
| 문서 열기 | ⌘O |
| 폴더 열기 | ⇧⌘O |
| 빠른 열기 | ⌥⌘O |
| 저장 | ⌘S |
| 다른 이름으로 저장 | ⇧⌘S |
| 모두 저장 | ⌥⌘S |
| 문서 닫기 | ⌘W |
| 창 닫기 | ⇧⌘W |
| 닫은 문서 다시 열기 | ⇧⌘T |
| 실행 취소·다시 실행 | ⌘Z / ⇧⌘Z |
| 찾기 | ⌘F |
| 찾기 및 바꾸기 | ⌥⌘F |
| 폴더 검색 | ⇧⌘F |
| 다음·이전 일치 | ⌘G / ⇧⌘G |
| 굵게·기울임·밑줄 | ⌘B / ⌘I / ⌘U |
| 링크 | ⌘K |
| 제목 1~6단계 | ⌘1~⌘6 |
| 일반 문단 | ⌘0 |
| 들여쓰기·내어쓰기 | ⌘] / ⌘[ |
| 줄을 위·아래로 이동 | ⌥↑ / ⌥↓ |
| 서식 지우기 | ⇧⌘R |
| 맞춤법 제안 | ⌥Return |
| 인쇄 | ⌘P |
| 설정 | ⌘, |

메뉴 막대에서도 각 명령의 단축키를 확인할 수 있습니다. 작성·원문·미리보기, 개요, 집중 모드는 **보기** 메뉴에서 선택합니다.

검색창이나 대화상자의 입력란에 커서가 있으면 실행 취소는 그 입력란에 적용됩니다. 문서의 편집 기록을 되돌리려면 문서로 포커스를 옮기세요.
