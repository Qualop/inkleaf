# 내보내기와 인쇄

## 문서 내보내기

**파일 → 내보내기**에서 형식을 선택합니다. 형식과 출력 설정을 함께 정하려면 **파일 → 내보내기 설정…**을 엽니다.

| 형식 | 쓰는 상황 |
| --- | --- |
| PDF | 페이지 단위로 읽거나 인쇄하고 의견을 받을 때 |
| HTML | 브라우저에서 서식이 있는 문서를 볼 때 |
| PNG·JPEG | 문서를 이미지로 전달할 때 |
| SVG | 브라우저 중심의 렌더링 결과가 필요할 때 |
| Markdown·일반 텍스트 | 다른 편집기나 작업에서 원문을 사용할 때 |
| Word·EPUB | 다른 문서 앱이나 전자책 앱으로 이어 갈 때 |

OpenDocument, RTF, LaTeX, reStructuredText, Textile, OPML, MediaWiki, GFM, CommonMark 변환도 제공합니다. 변환기 기반 형식에는 Pandoc을 사용하며 Mac 배포본에 포함되어 있습니다. 다른 실행 파일을 쓰려면 **설정 → 내보내기**에서 경로를 정합니다.

## 출력 모양 정하기

내보내기 옵션에서 해당 형식에 맞는 제목, 저자, 목차, 문서 테마, 어두운 배경 등을 선택합니다. 렌더링 기반 형식에는 용지, 여백, 너비, 품질, 머리글·바닥글 등의 설정이 있습니다. 변환기 형식에는 템플릿 등 관련 옵션이 표시됩니다.

설정에 이름을 붙여 프리셋으로 저장할 수 있습니다. **이전 설정으로 내보내기**는 현재 문서에서 마지막으로 사용한 내보내기 설정을 다시 사용합니다.

내보내기는 별도 결과 파일을 만듭니다. 편집할 원문을 남기려면 Markdown 문서도 저장하세요. 다른 형식으로 변환하면 문서 모양이 달라질 수 있습니다.

## 인쇄하기

**⌘P** 또는 **파일 → 프린트…**를 선택합니다. Mac 인쇄 미리보기에서 내용을 확인한 뒤 프린터나 시스템 PDF 옵션을 선택합니다.

## Word와 EPUB 가져오기

**파일 → 문서 가져오기…**를 선택합니다. 변환한 문서는 편집 가능한 Markdown으로 열립니다. 지원하는 Word·EPUB 가져오기는 포함된 이미지를 임시 문서와 함께 추출합니다. 처음 저장할 때 Markdown의 위치를 정하고 참조 이미지를 함께 저장합니다.

정확한 원본 서식이 필요하면 기존 파일도 보관하세요. 가져오기는 원래 Word나 EPUB를 직접 고치는 기능이 아니라 Markdown으로 변환하는 기능입니다.
