# 문제 해결

## 처음 실행이 macOS에서 차단됩니다

현재 커뮤니티 배포본은 Developer ID 서명과 Apple 공증을 받지 않았습니다. [공식 릴리스](https://github.com/Qualop/inkleaf/releases/latest)에서 받은 파일인지 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안**의 안내를 따르세요. 다운로드에는 체크섬도 함께 제공됩니다. 시스템 전체의 보안 설정을 끄지는 마세요.

## Markdown 기호가 그대로 보입니다

**보기 → 작성**과 **Markdown 원문** 중 어느 쪽인지 확인합니다. 작성 모드에서도 편집 중인 블록에는 기호가 표시됩니다. 편집하지 않고 읽으려면 미리보기를 선택합니다.

## ‘임시 문서 보관됨’이라고 나옵니다

로컬 복구 데이터를 보관했다는 뜻입니다. 파일 자체를 저장하려면 **⌘S**를 누르세요. 이름 없는 새 문서는 저장 위치를 정해야 일반 파일로 자동 저장할 수 있습니다. [저장과 복구](files-and-recovery.md)를 참고하세요.

## Markdown을 옮겼더니 이미지가 사라졌습니다

이미지의 상대 경로가 실제 파일을 가리키는지 확인합니다. 이미지 폴더를 문서와 함께 옮기거나, 원래 문서에서 다른 이름으로 저장을 사용해 참조 이미지를 새 위치에 복사합니다. 외부 이미지라면 해당 서버에 접속할 수 있어야 합니다.

## 맞춤법 제안이 문장에 맞지 않습니다

**설정 → 맞춤법과 사전**의 검사 언어를 확인합니다. 이름이나 전문 용어는 개인 사전에 넣을 수 있습니다. macOS 문법 검사는 언어마다 지원이 다르며, 밑줄은 최종 판단이 아니라 제안입니다.

## 수식이나 다이어그램에 오류가 표시됩니다

원문에서 구분 기호와 문법을 확인합니다. 수식은 `$…$` 또는 `$$…$$`, Mermaid는 `mermaid` 코드 블록을 사용합니다. [짧은 예제](images-math-diagrams.md)부터 표시되는지 확인한 뒤 내용을 늘려 보세요.

## 변환기로 내보내지 못합니다

Word, EPUB 등 변환기 형식이라면 **설정 → 내보내기**의 Pandoc 경로를 확인합니다. Mac 배포본에는 Pandoc이 포함되어 있으며, 별도로 지정한 경로가 우선합니다. 오래된 사용자 경로를 지우면 포함된 변환기를 다시 사용할 수 있습니다. 출력 문제를 해결하는 동안 원본 Markdown은 보관하세요.

## 업데이트를 확인하거나 설치하지 못합니다

온라인 상태에서 **Inkleaf → 업데이트 확인…**을 다시 선택합니다. 마운트한 DMG가 아니라 응용 프로그램 폴더에서 실행하세요. 0.1.2 이하 버전은 업데이트 기능이 있는 버전을 한 번 설치해야 합니다. 개발용 `--data-dir`, `--web-root`로 실행한 경우에는 업데이트 확인이 비활성화됩니다.

## 문제 제보하기

[이슈](https://github.com/Qualop/inkleaf/issues)에 앱 버전, macOS 버전, 실행한 순서와 실제 결과를 적어 주세요. 개인 문서 대신 같은 현상을 보여 주는 짧은 예제를 사용하세요. 화면 문제라면 스크린샷도 도움이 됩니다.
