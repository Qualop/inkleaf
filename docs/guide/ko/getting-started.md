# 설치와 시작하기

## 설치하기

다운로드 빌드는 Apple Silicon Mac과 macOS 14.5 이상을 지원합니다.

1. [최신 릴리스](https://github.com/Qualop/inkleaf/releases/latest)를 엽니다.
2. DMG를 내려받아 열고 **Inkleaf**를 **응용 프로그램** 폴더로 옮깁니다. PKG 설치 파일을 실행해도 됩니다.
3. 응용 프로그램 폴더에서 Inkleaf를 실행합니다.

현재 커뮤니티 빌드는 Developer ID 서명과 Apple 공증을 받지 않았습니다. 처음 실행이 차단되면 공식 릴리스에서 받은 파일인지 확인하고 **시스템 설정 → 개인정보 보호 및 보안**에 표시되는 안내를 따르세요.

## 첫 문서 쓰기

1. **파일 → 새로 만들기** 또는 **⌘N**을 누릅니다.
2. `# 나의 메모`처럼 제목을 쓰고 아래에 문단을 이어 씁니다.
3. **⌘S**를 눌러 폴더와 파일 이름을 정하고 `.md`로 저장합니다.

기존 파일은 **⌘O**로 엽니다. 제목, 할 일 목록, 표가 있는 [생각 모음 예제](../../examples/생각%20모음.md)를 열어 시작해도 좋습니다.

## 화면의 도구 찾기

왼쪽 아래에는 사이드바, Markdown 원문 전환, 문서 메뉴가 있습니다. 오른쪽 아래의 단어 수를 누르면 문서 통계가 열립니다. 전체 명령은 Mac 메뉴 막대의 파일·문단·서식·보기 메뉴에서 찾을 수 있습니다.

**보기 → 작성**은 서식을 보며 편집하는 화면입니다. **Markdown 원문**은 기호를 그대로 보여 주고, **미리보기**는 편집하지 않고 읽는 화면입니다.

## 화면 언어 바꾸기

**Inkleaf → 언어 → 한국어** 또는 **English**를 선택합니다. 메뉴와 설정의 언어가 바뀌며 문서 내용은 번역되지 않습니다.

## 업데이트하기

**Inkleaf → 업데이트 확인…**을 선택합니다. 새 버전이 있으면 내려받고 **설치 및 재실행**을 선택할 수 있습니다. 앱은 종료 전에 기존 문서 보존 절차를 거칩니다.

**자동으로 업데이트 확인**으로 정기 확인을 켜고 끌 수 있습니다. 기본값은 켜짐이며, 설치가 기본으로 자동 진행되지는 않습니다. 업데이트 기능이 없는 0.1.2 이하 버전은 새 버전을 한 번 직접 설치해야 합니다.
