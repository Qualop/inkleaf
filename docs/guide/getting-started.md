# Getting started

## Install

The Mac download supports Apple Silicon and macOS 14.5 or later.

1. Open the [latest release](https://github.com/Qualop/inkleaf/releases/latest).
2. Download the DMG, open it, and drag **Inkleaf** into **Applications**. Alternatively, use the PKG installer.
3. Launch Inkleaf from Applications.

The community build is ad-hoc signed and is not Apple notarized. If macOS blocks the first launch, follow the message in **System Settings → Privacy & Security**. Install only a copy you obtained from the project's release page.

## Create your first document

1. Choose **File → New** or press **⌘N**.
2. Type a heading such as `# My notes`, then add a paragraph.
3. Press **⌘S**, choose a folder and filename, and save the document as `.md`.

Use **⌘O** to open an existing file. Try the included [Field Notes example](../examples/Field%20Notes.md) if you want a document with headings, tasks, and a table.

## Find the controls

The bottom-left controls open the sidebar, toggle Markdown source, and open the document menu. The word count at the bottom right opens document statistics. The Mac menu bar contains the full set of writing, file, and export commands.

Use **View → Write** to edit with formatting, **Markdown Source** to inspect the markup, and **Preview** to read without editing.

## Change the interface language

Choose **Inkleaf → Language → English** or **한국어**. This changes the interface; it does not translate your document.

## Update Inkleaf

Choose **Inkleaf → Check for Updates…**. If an update is available, the update window lets you download it and choose **Install and Relaunch**. The app uses its normal document-preservation steps before quitting.

**Automatically Check for Updates** controls scheduled checks. Automatic checking starts enabled; updates are not silently installed by default. Version 0.1.2 and older require one ordinary installation of a version with the updater.
