# Files, search, and recovery

## Open files and folders

- **File → Open…** (**⌘O**) opens a document.
- **File → Open Folder…** (**⇧⌘O**) opens a folder in the Files sidebar.
- **File → Quick Open…** (**⌥⌘O**) finds a file by name among known and recent files.
- **View → Files** shows open documents and folder navigation.

You choose where documents live. A folder does not need a special project format.

## Navigate a longer document

Choose **View → Outline**. Select a heading to jump to it. Filter headings, limit heading depth, or collapse sections to keep a large outline manageable.

![The heading outline beside a document](../screenshots/outline.png)

## Search and replace

Press **⌘F** for document search. Enter a query and use Next or Previous. Case, Regex, and Word options change matching. Enter replacement text and choose Replace or Replace All when needed.

For several files, open a folder first and choose **Edit → Find → Search Folder…** (**⇧⌘F**). Select a result to open its document. Use the cancellation control for an ongoing operation.

## Know what has been saved

| State | Meaning |
| --- | --- |
| Saved file | Your latest saved text is in the file at its chosen location. |
| Unsaved file changes | The open document has edits that still need to be written to its file. |
| Draft kept | Inkleaf has local recovery data. This does not save or replace the original file. |

Press **⌘S** to save. Use **File → Save As…** (**⇧⌘S**) for another location. When moving a document with local images to another folder, use Save As so referenced images can be published with the document.

Automatic saving is off initially. Enable **Settings → General → Automatically save changed files** if you want existing files written as you work. A new document still needs a save location.

## Restore unfinished work

In **Settings → General**, enable reopening documents and keeping unsaved drafts. **File → Recover Unsaved Documents…** opens available recovery snapshots. Save a recovered document when you want its text written to a file.

If another app changes the same file, Inkleaf checks the disk version. When both copies have edits, keep your open work and resolve the save choice; Save As is useful when you want a separate copy.

Click the bottom-right word count for document statistics, encoding, and line-ending controls. Changing encoding selects the next saved byte format; save to write it to disk.
