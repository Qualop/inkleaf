# Keyboard shortcuts

These shortcuts refer to the Mac app. ⌘ is Command, ⌥ is Option, and ⇧ is Shift.

| Action | Shortcut |
| --- | --- |
| New document | ⌘N |
| New window | ⇧⌘N |
| Open a document | ⌘O |
| Open a folder | ⇧⌘O |
| Quick Open | ⌥⌘O |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save All | ⌥⌘S |
| Close document | ⌘W |
| Close window | ⇧⌘W |
| Reopen closed document | ⇧⌘T |
| Undo / Redo | ⌘Z / ⇧⌘Z |
| Find | ⌘F |
| Find and Replace | ⌥⌘F |
| Search folder | ⇧⌘F |
| Next / previous match | ⌘G / ⇧⌘G |
| Bold / Italic / Underline | ⌘B / ⌘I / ⌘U |
| Link | ⌘K |
| Heading levels 1–6 | ⌘1 through ⌘6 |
| Plain paragraph | ⌘0 |
| Indent / Outdent | ⌘] / ⌘[ |
| Move line up / down | ⌥↑ / ⌥↓ |
| Clear formatting | ⇧⌘R |
| Spelling suggestions | ⌥Return |
| Print | ⌘P |
| Settings | ⌘, |

The menu bar shows the shortcut beside each command. Source, Write, Preview, outline, and focus controls are also available through **View**.

When a search field or dialog input owns focus, Undo and Redo apply to that input. Move focus back to the document to use its edit history.
